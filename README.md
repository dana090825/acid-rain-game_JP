# 🌧️ 산성비 - 일어판 (Acid Rain - JP Edition)

위에서 떨어지는 **일본어 단어**의 **한국어 뜻**을 입력해 점수를 얻는 타자 게임입니다.
단어가 바닥에 닿기 전에 뜻을 맞혀 목숨을 지키세요!

> 심심해서 재미로 만든 프로젝트이니 넓은 아량으로 즐겨주세요 :>

## 🎮 플레이 방법

1. 인트로 화면에서 **게임 시간(초)** 과 **난이도**를 설정합니다.
2. `시작하기` 를 누르면 게임이 시작됩니다.
3. 위에서 일본어 단어가 떨어집니다. 뜻을 **한글로 입력** 후 `Enter` 또는 `입력` 버튼을 누릅니다.
4. 맞히면 점수 +1, 단어를 놓치면 목숨이 1개 줄어듭니다.
5. 시간이 다 되거나 목숨이 모두 소진되면 게임이 종료됩니다.

## ✨ 주요 기능

- ⏱ **제한 시간 설정** — 인트로에서 직접 초 단위로 조절
- ⚙ **난이도 3단계** — 단어 낙하 속도와 동시 등장 개수가 달라짐
  | 난이도 | 등장 간격 | 속도 | 동시 등장 |
  |--------|----------|------|-----------|
  | 쉬움 (easy) | 2.2초 | ×0.8 | 3개 |
  | 보통 (normal) | 1.8초 | ×1.0 | 4개 |
  | 어려움 (hard) | 1.4초 | ×1.2 | 5개 |
- ❤️ **목숨 시스템** — 5개에서 시작, 단어를 놓칠 때마다 감소
- 🏆 **최고 점수 저장** — `localStorage` 기반으로 브라우저에 기록 유지
- ❌ **오답 모아보기** — 게임 종료 후 틀린 단어(일본어 / 정답 / 내 입력) 확인
- 📚 **단어 데이터 69개** — 인사·감정·장소·동사 등 기초 일본어 단어 수록

## 🛠 기술 스택

- **Vanilla JavaScript / HTML / CSS** — 프레임워크·빌드 도구·의존성 없음
- 데이터: `assets/words.json`
- 저장소: 브라우저 `localStorage`

## 🚀 실행 방법

`fetch`로 `words.json`을 불러오기 때문에 **정적 서버를 통해 실행**해야 합니다.
(`file://` 로 직접 열면 단어가 로드되지 않습니다.)

**VS Code Live Server 사용 시**
1. 확장 프로그램 `Live Server` 설치
2. `index.html` 우클릭 → `Open with Live Server`

**간단한 로컬 서버 사용 시**
```bash
# Python 3
python -m http.server 5501

# 또는 Node
npx serve
```
이후 브라우저에서 `http://localhost:5501` 접속
